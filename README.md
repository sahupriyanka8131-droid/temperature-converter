
# Temperature Converter Website 🌡️

## About Project
This is a Temperature Converter Website created using HTML, CSS and JavaScript.

It helps users convert temperature between Celsius, Fahrenheit and Kelvin.

## Features
- Celsius to Fahrenheit conversion
- Fahrenheit to Celsius conversion
- Celsius to Kelvin conversion
- Fahrenheit to Kelvin conversion
- Kelvin to Celsius conversion
- Kelvin to Fahrenheit conversion
- Input validation
- Absolute zero error handling
- Convert and Reset buttons
- Responsive design

## Technologies Used
- HTML5
- CSS3
- JavaScript

## How to Use
1. Open the website.
2. Enter a temperature value.
3. Select the input unit.
4. Click on the Convert button.
5. View all conversion results.
